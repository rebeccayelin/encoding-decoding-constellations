# Documentation

This folder is for project context and process documentation that should not appear directly on the website unless intentionally adapted into web copy.

## Notes

Use `notes/` for process notes, PDFs, drafts, references, press links, installation details, technical notes, and anything else that may be useful context for future revisions.

## Working Notes

If something later becomes important enough to cite, summarize, or adapt into the site, add a short note explaining what it is and why it matters.
